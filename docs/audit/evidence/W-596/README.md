# تعديلُ إحاطاتِ جولةِ دفعةِ J1 قبلَ الإطلاقِ (W-596)

## التعريف
دليلُ قيدِ `W-596`: تعديلٌ مؤرَّخٌ لإحاطاتِ الجولةِ **قبلَ الإطلاقِ** (لم تُطلَقْ بعدُ) وفقَ مراجعةِ المستشارِ: (1) تصحيحُ العقدةِ المرادِّ مراجعتُها إلى رأسِ فرعِ w-594-v2 ليشملَ تصحيحَ لقطاتِ القياسِ ومُثبَّتاتِ الحارسِ (W-595) — كانت تشيرُ إلى 529cc391 الناقصةِ الإصلاحِ · (2) إضافةُ الأوامرِ 19–21 (فحوصُ المُثبَّتاتِ وفرقُها وعقدُ نَسَبِ القياساتِ) وتعميمُ فرقِ الملفّاتِ (الأمرُ 4) · (3) تحديدُ سؤالِ الحكمِ في T6 (التعويضُ الآليُّ أم المُعوِّضُ المسجَّلُ — يُحاكِمُهُ المقعدُ منَ النصِّ المعتمدِ لا من تقريرِ المنفِّذِ) وفي الطفراتِ (للمقعدِ إعادتُها في نسخةٍ معزولةٍ) · (4) تصحيحٌ مؤرَّخٌ في قياساتِ W-593: «عامّةٌ قبل» = 202 لا 201 · (5) فرقُ المواضعِ بينَ العقدتَينِ مسجَّلًا.
