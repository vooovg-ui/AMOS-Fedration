# بطاقةُ هويةِ مجلَّدِ خُطّافاتِ الدفعِ

## التعريف
حفظُ خُطّافِ `pre-push` مصدرًا متتبَّعًا في الشجرةِ لا ملفًّا محليًّا يُنسى —
فيُثبِّتُهُ `bootstrap.sh` في `.git/hooks/` بلا اكتشافٍ متأخِّرٍ (WI-078).

## النطاق
خُطّافاتِ git المحفوظةُ في المستودعِ وحدَها. ما يُخصُّ البيئةَ المحليةَ
لا يُخزَّنُ هنا.
