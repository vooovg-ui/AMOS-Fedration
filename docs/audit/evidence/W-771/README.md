# evidence/W-771 — إعادةُ أمرِ المالكِ بتغييرِ عائلاتِ المجلسِ (Q-91 · الإصدارُ الثالثُ) + قياسُ توفرٍ جديدٌ بتجربةٍ فعليةٍ

## التعريف
تنفيذُ قرارِ المالكِ **Q-91** (2026-11-01 · أمرٌ مباشرٌ · نصُّهُ حرفيًّا نصُّ توجيهَي Q-85/Q-86 نفسُهُ): إعادةُ أمرِ تغييرِ عائلاتِ المجلسِ معَ توكيدٍ رابعٍ حرفيٍّ لقاعدةِ تسلسلِ الجولاتِ (§ 8 بند 5 · سابقةُ W-678/W-714/W-745/W-753). البدائلُ بمعيارِ § 1.9 الكتالوجيِّ المُقاسِ (سندُ Q-86)، والقياسُ هذهِ المرةَ **تجربةُ إطلاقٍ فعليةٌ** لا قراءةُ عرضٍ: ستةُ مقاعدَ عبرَ خمسِ عوائلَ معروضةٍ مُتمايزةٍ، ردَّتِ المنصةُ على كلِّ واحدٍ منها بأنه ليسَ على خطةِ الحسابِ ويُشغَّلُ بـClaude Opus 5.5، وأعلنَتِ المقاعدُ الستةُ ذاتيًّا أنها Claude (Anthropic).

## الحكمُ المقيسُ
- خطةُ الحسابِ تُشغِّلُ عائلةً واحدةً فعلًا (Anthropic · Claude Opus 5.5) رغمَ عرضِ سبعِ عوائلَ ⇒ لا نصابَ ثلاثيًّا (§ 1.1) ولا ثنائيًّا (§ 1.2).
- الجولةُ الواحدةُ المأذونةُ (المستشارُ 31 § 1 · إحاطاتُ W-744 المختومةُ) **تبقى مؤجَّلةً** بقرارِ D30 (لا يُخفَّضُ النصابُ · لا جولةَ Claude خالصةً — لم يأذنْ بها Q-85 ولا Q-86 ولا Q-91).
- بمجردِ أن تُشغِّلَ خطةُ الحسابِ ثلاثَ عوائلَ متمايزةٍ (أو اثنَينِ معَ تعذُّرٍ مقيسٍ للثالثةِ) **تُشكَّلُ المقاعدُ وتُطلَقُ الجولةُ بلا قيدِ بروتوكولٍ جديدٍ ولا قرارٍ جديدٍ** (§ 1.9 · سابقةُ Q-86).
