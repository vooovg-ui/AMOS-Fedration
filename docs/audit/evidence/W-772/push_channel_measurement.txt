## 3. السببُ مقيسًا: أمرُ تحديثِ مرجعٍ واحدٍ بلا حزمةٍ عبرَ POST …/git-receive-pack (pkt-line يدويًّا)
الأمر: 0000…0000 6d7a1863… refs/heads/curl-test-branch
الرد: HTTP 200 · "unpack no voting servers succeeded" · "ng refs/heads/curl-test-branch failed"
⇒ الخادمُ (GitHub spokes) يرفضُ كلَّ كتابةٍ عبرَ git receive-pack — عطبٌ في جهةِ الخادمِ لا في الشجرةِ ولا في الاعتماد.

## 4. واجهةُ REST تعملُ للكتابة
POST repos/…/git/refs  ref=refs/heads/api-test-branch sha=6d7a1863  → 201 (أُنشئَ فرعُ اختبارٍ)
DELETE repos/…/git/refs/heads/api-test-branch                          → 422 "Repository rule violations found · Cannot delete this branch"
⇒ فرعُ الاختبارِ `api-test-branch` باقٍ على 6d7a1863 (عقدةُ main السابقة · لا محتوى جديد) — حذفُه بيدِ المالكِ (قاعدةُ المستودع).
