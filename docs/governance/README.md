# docs/governance — حوكمة العمل

## التعريف
هذا المجلد يحتوي القواعد التي تحكم **طريقة العمل** في المستودع، لا محتوى العمل.
الدستور في `core/constitution/` يحكم الدولة؛ وهذا المجلد يحكم من يبني الدولة.
كل مبرمج أو وكيل يعمل في AMOS-Federation ملزم بما فيه قبل أن يكتب سطرًا واحدًا.

## النطاق
**يدخل:** مبدأ العمل، دورة المراحل، قواعد المنع، بوابات الإنفاذ.
**لا يدخل:** المواد الدستورية (في `core/constitution/`)، المراسيم (في `royal/decrees.md`)، خطط التنفيذ (في `docs/audit/`).

## الترتيب الهرمي للمرجعية

```
core/constitution/                  ← دستور الدولة
docs/governance/WORKING_PRINCIPLE.md ← مبدأ عمل البُناة   ← أنت هنا
docs/audit/PHASE_E_ROADMAP.md       ← خطة السجل
docs/audit/TRUTH_MATRIX.md          ← الحقيقة المقاسة
docs/governance/work/               ← طريق العمل: من يعمل على ماذا الآن
```

**الفرق بين المبدأ والطريق:** `WORKING_PRINCIPLE.md` يحكم **كيف** يُبنى العمل
(المنع، الحالات، `DONE = Capability Proven`). و`work/` يحكم **من** يبنيه و**متى**
ومن يملك النطاق — فلا يبدأ عملٌ بلا قيد، ولا يُكرَّر عملٌ بين جهتين، ولا يمرّ دمجٌ
بلا تحديث سجلّه.
