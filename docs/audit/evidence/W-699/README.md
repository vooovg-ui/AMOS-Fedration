# أدلّةُ دفعةِ W-699 — شِّفرةُ E1 النصفُ الثاني: أسطحُ agent_runtime الثمانيةُ تعبرُ الحدَّ السياديَّ

## التعريف

دفعةُ الشِّفرةِ الثانيةُ والأخيرةُ من E1 (WI-119 · بتصميمِ W-694 المودَعِ
واعتمادِ المالكِ الحرفيِّ Q-73 «اعتماد تصميم E1 (13 اسمًا)»): الأسطحُ
الثمانيةُ في `agent_runtime` عبرتِ الحدَّ السياديَّ بنوى كتابةٍ خاصّةٍ
بلا تعشيشٍ ومعوّضاتٍ مربوطةٍ:

- `health.py` — `check_agent` (run_health_check) · `start_treatment`
  (بدءٌ وإتمامٌ في جلستَينِ مُتميِّزتَينِ بمفتاحَينِ — تصميمُ § 2.5) ·
  `isolate` (أثرانِ في عبورٍ واحدٍ) · `log_action` (log_isolated_action) ·
  `release` (release_agent بمعوّضَينِ — السجلُّ والحالةُ — وتحقُّقٍ مسبقٍ
  بفعلِ اتجاهِ القرارِ قبلَ أيِّ كتابةٍ)
- `population.py` — `register_agent` (spawn_agent بمفتاحِ نطاقٍ مميَّزٍ
  `agents.population.spawn` · أثرانِ: هويّةٌ + صفُّ سكّانٍ) · `update_state`
  (تحقُّقٌ مسبقٌ ← عبورٌ كانونيٌّ ← عبورُ المرآةِ مستقلًّا) · `take_step`
  (record_curriculum_step)

معَ فحوصِ الأصنافِ الخمسةِ (41 فحصًا في
`tests/test_w699_agent_runtime_crossing.py`) ومحرّكِ الطفراتِ (15 حالةً مهيكلةً)
(نزعُ حارسِ فعلٍ واحدٍ في كلِّ مرةٍ ← فشلُ فحصِ سطحِهِ على الدليلِ الحرفيِّ
`failed_on_evidence`) · وقياسُ القبولِ: الدَّينُ **129 ← 121**
(الإسقاطُ الكاملُ الموعودُ) والسياديّةُ **51 ← 59**.
