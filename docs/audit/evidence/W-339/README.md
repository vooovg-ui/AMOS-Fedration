## ما قِيسَ (2026-10-15 · بيئةُ منفِّذٍ محليّةٍ · PostgreSQL 18.6)

| المعيار | القياس | النتيجة |
|---|---|---|
| مصدرُ المخططِ = الهجراتُ | `طبّقَ 19 هجرةً (001_init…019_convert…)` | ✓ |
| كتابةٌ عبرَ مسارِ الخدمةِ | `PersistentSystemStateStore.set_level` + `PersistentPromotionStore.create` | ✓ (المرجعُ ما أعاده المسارُ) |
| النسخُ | `pg_dump --format=custom` ⇒ 311,963 بايت | ✓ |
| الاستعادةُ | `pg_restore` إلى قاعدةٍ فارغةٍ معزولةٍ ثانيةٍ | ✓ |
| التحققُ من اتصالٍ جديدٍ | قراءةٌ بمحرّكٍ جديدٍ كليًّا ⇒ **صفرُ اختلافٍ** | ✓ |
| قابليةُ التكرارِ | تشغيلانِ مستقلّانِ (الأداةُ + 4 فحوصِ pytest) | ✓ |
| السلبيّاتُ | تالفةٌ ⇒ `pg_restore: error: input file does not appear to be a valid archive` · مفقودةٌ ⇒ رفضٌ قبلَ الأداةِ · على المصدرِ ⇒ رفضُ حارسِ الأمانِ | ✓ الثلاثةُ كما يجبُ |
| حزمةُ الجذرِ والحوكمةِ | تُقاسُ قبلَ الدفعِ (البواباتُ) | أدناه |

# الإثباتُ الكاملُ (خرجٌ 0)
AMOS_RUN_POSTGRES_TESTS=1 AMOS_TEST_DATABASE_URL=postgresql://… AMOS_DB_SSLMODE=disable \
  python tools/ops/pg_backup_restore.py prove --artifacts /tmp/wi076_local
