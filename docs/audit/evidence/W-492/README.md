## توجيهاتُها المنفَّذةُ في القيدِ نفسِهِ
- حفظُ النصِّ حرفيًّا (هذهِ البطاقةُ و`review.txt`) بقيدٍ جديدٍ (N+1).
- تسجيلُ تبليغَي § 9 اكتشافَينِ بجديدَينِ: `DISC-106` (حارسُ الحجزِ يرفضُ مساراتَ غيرِ ASCII محجوزةً خطأً) و`DISC-107` (عملٌ على `WI-097` قبلَ انتقالاتِهِ) — والحارسُ **يُصلَحُ ببندٍ** (`WI-098` · `PROPOSED`) لا بتجاوزٍ.
- PR #76 يبقى غيرَ مدموجٍ حتى يُدمجَ #77 ثمَّ يُعادَ تشغيلُهُ فوقَ main المعالَجةِ وتُقرأَ تغطيتُهُ على عقدتِهِ هوَ.
