# دليلُ قيدِ W-678 — استلامُ الخطِّ المفتوحِ وتوجيهُ المالكِ الجديدُ (تسلسلُ الجولاتِ) وقياسُ موتِ إطلاقِ W-677

## التعريف

قيدُ منفِّذٍ جديدٍ يستلمُ الجلسةَ بالأمرِ الدائمِ (سابقةُ W-644/W-659/W-666):
قياساتُ الافتتاحِ · قياسُ استحالةِ جمعِ أحكامِ جولةِ W-677 (إطلاقُها انتهى بلا
حكمٍ مودَعٍ) · حفظُ توجيهِ المالكِ الجديدِ (منعُ الجولاتِ المتزامنةِ) نصًّا
حرفيًّا وإضافتُهُ نصًّا حرفيًّا مؤرَّخًا إلى بروتوكولِ المجلسِ (§ 8 البندُ 5 —
مسارُ ملفِّ البروتوكولِ مُعلَنٌ في صفِّ WI-100 النشطِ). لا شِفرةَ إنتاجيّةً ولا
تغييرَ حالةِ بندٍ في هذا القيدِ.

## النطاق

أدلّةُ الاستلامِ والقياسِ والتوجيهِ — لا شِفرةَ. الخطُّ المستلَمُ: `PR #154`
(الفرعُ `w-677-council-launch` · رأسُهُ `dae5725f` فوقَ main). البندانِ صاحبا
الجولتَينِ المأمورتَينِ: [`WI-113`](../../governance/work/ACTIVE_WORK.md) و
[`WI-115`](../../governance/work/ACTIVE_WORK.md) (مُعلَنٌ في صفَّيهما — الجولةُ
لـWI-113 أوّلًا ثمَّ WI-115 بعدَها).
