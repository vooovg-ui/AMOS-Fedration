# دليلُ قيدِ W-670 — WI-115: إصلاحُ § 3.5 (إعادةُ صرفٍ لحركةٍ معكوسةٍ تُرفَض)

## التعريف
دليلُ قيدِ `W-670`: `StateTreasury._existing_idempotent` يرفعُ `EntityStateError` إن كانت الحركةُ بالمفتاحِ نفسِه حالتُها `reversed`، فلا تُعادُ «نجاحًا متطابقًا» (`idempotent=True`) — والفحصُ: صرفٌ ← عكسٌ ← إعادةُ الصرفِ بالمفتاحِ نفسِه، وبقاءُ الإعادةِ المتطابقةِ لحركةٍ قائمة.

## النطاق
الجزءُ الأوّلُ من WI-115 (وثيقةُ التصميمِ § 2.1) — قبلَ كاشفِ التعشيشِ وقبلَ أيِّ تصميمٍ لـM1. ليس حرقًا لـD-4 (لا موضعَ كتابةٍ عبرَ الحدَّ).
