# أدلّةُ دفعةِ W-689 — شِفرةُ تحصينِ WI-117: حارسُ require_king على المساراتِ الخمسةِ

## التعريف

تنفيذُ التصميمِ المودَعِ في W-687 ([`docs/audit/WI117_KING_GUARD_DESIGN.md`](../WI117_KING_GUARD_DESIGN.md) § 2):
إغلاقُ الثغرةِ الحيّةِ المُعلَنةِ في التوجيهِ 24 («مواطنٌ برمزٍ سليمٍ يرفعُ زرَّ التوقّفِ
ويوقّعُ موافقةً») على main:

1. **الحارسُ ×4**: `require_king` بدلَ `require_auth` على — reset الخدمتَينِ
   (`governance/main.py:149` و`control_console/main.py:211`) وإنشاءِ الترقيةِ
   (`governance/main.py:170`) وفحصِ البوّابةِ (`governance/main.py:203`).
2. **تحصينُ `sign_approval`** (`control_console/main.py:233`): الحارسُ ملكيٌّ
   و`signed_by` صارَ منَ الرمزِ (`token_data["sub"]`) لا منَ جسمِ الطلبِ —
   حُذِفَ الحقلُ منَ `ApprovalRequest` وسجلُّ التدقيقِ والحدثُ يوقّعانِ بالهويّةِ الموثَّقةِ.
3. **«التفعيلُ» يبقى** بنصِّ D25-2 (الخفضُ المتنكّرُ يرفضُهُ الحدُّ السياديُّ — W-675/WI-114).
4. **فحوصٌ**: ملفٌّ جديدٌ `test_wi117_king_guard_routes.py` (10 فحوصٍ: مواطنٌ/ملكٌ لكلِّ
   مسارٍ) + تحديثُ 6 فحوصٍ تمرُّ برمزِ مواطنٍ إلى رمزِ ملكٍ + فحصانِ سلبيّانِ جديدانِ
   (مواطنٌ ممنوعٌ · موقِّعٌ مزيّفٌ يُهمَلُ).
5. **الطفرةُ**: إسقاطُ حارسِ reset ⇒ فحصانِ المواطنِ يفشلانِ ([`mutations/`](mutations/README.md)).
6. **مسبارُ HTTP حقيقيٌّ** ([`http_probe.py`](http_probe.py) · الخامُّ [`http_probe_raw.txt`](http_probe_raw.txt)):
   خدمتانِ حقيقيّتانِ بـuvicorn — الملكُ 200/201 في الخمسةِ، والمواطنُ 403 في الخمسةِ
   والمستوى halt باقيًا، و`signed_by` منَ الرمزِ لا منَ الجسمِ.
